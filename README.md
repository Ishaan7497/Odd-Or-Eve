# Odd or Eve

A digital implementation of the traditional Indian hand game "Odd or Eve" (Hand Cricket).

## About

Inspired by the traditional Indian hand game Odd or Eve (Hand Cricket), this project digitizes a game that children commonly play using fingers and quick mental math. The Python program simulates the same rules in a command-line environment, allowing the player to face off against the computer.

## Game Rules
- Players take turns throwing out fingers (0-5)
- Guess if the total will be odd or even
- Track scores and compete

## Features
- Command-line interface
- Computer AI opponent
- Traditional game rules
- Python implementation

## Installation

Clone the repository:

```bash
git clone https://github.com/Ishaan7497/Odd-Or-Eve.git
cd Odd-Or-Eve
python odd_or_eve.py
```

## How to Play

1. Run the game
2. Choose your move (0-5 fingers)
3. Predict odd or even
4. Score points and win!
